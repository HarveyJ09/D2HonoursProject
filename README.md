# D2HonorsProject
Harvey Jarvis's Honours Project Repository

Functionality:
Transferring and Equipping items - Uses a drag and drop system, drag the item you want to the section you want the item to go.
Viewing items - Click on the item to get its stats 
Refesh button - Top right indicated by the refresh logo (an arrow)
Logout button - Top right indicated by logout logo (door and arrow)
Search bar - Click to activate and type

REMINDER - You can only equip 1 exotic item at a time per weapons and armor. You will error trying to equip an item to a character with a full inventory.
